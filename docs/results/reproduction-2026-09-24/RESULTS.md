## 可以得出的结论

1. **当前最明确的正面证据是结构化、高层控制。** Jev 在 Panda 高层技能组完成 9/9，在 Meta-World 两层控制完成 5/6，并且本轮 Meta-World 成本约为已尝试 GPT 组的 1/96。
2. **不能据此宣称 Jev 已普遍提升具身智能。** Panda 的纯 GPT 只跑了一个冒烟用例；Meta-World 的 GPT 只覆盖 2/6；二者都受当前中转端点的超时或结构化输出错误影响。
3. **LIBERO 本轮没有真正比较到 Jev。** 两组都先调用同一个 GPT 视觉规划器，目标在安全校验时越界，混合组的 Jev 调用数为 0。因此它只暴露了视觉规划器与工作区约束的兼容问题。
4. **Jev 不适合直接承担当前低层逐步控制。** Panda 的 Jev 逐步 XYZ 冒烟在 50 次调用后仍未抬起物体；高层技能选择才是当前有效接入点。

## Meta-World 协议

- 任务：`reach-v3`、`push-v3`、`pick-place-v3`，每项 seed 0/1。
- 两组均使用特权状态、两层“子目标 + XYZ/夹爪”控制。
- 每局最多 200 环境步、80 次模型调用、600 秒；动作重复 5 次。
- 成功只采用 Meta-World 官方 `info.success`。
- Jev 唯一失败为 `push-v3 / seed 0` 达到步数上限。
- GPT 两次请求均收到 HTTP 200，但后续动作结构校验失败。其覆盖率是 2/6，不能写成 0/6。

## LIBERO 协议

- 官方 LIBERO 固定 revision `8f1084e3132a39270c3a13ebe37270a43ece2a01`。
- 任务：`LIBERO-90 / task 0 / init 0`，关闭橱柜顶层抽屉。
- 两组使用完全相同的初始状态、外部相机和腕部相机 RGB-D。
- `waypoint-v1` 中两组共享 GPT-6 Astra 视觉规划器；区别只在局部控制由 GPT 或 Jev 完成。
- 两次视觉规划产生的像素目标加高度偏移后均越出声明工作区，因此安全层在动作执行前终止。
