## 逐步 XYZ 失败分析

`transfer / seed 0` 在 50 个周期和 50 次调用后以 `exhausted` 结束。物体最大抬升为 0 m，说明任务并未进入有效抓取阶段。

50 个动作全部通过安全预演并被执行，违规接触为 0。最终末端位置为 `[0.41852, 0.18169, 0.37029]`，已经移动到目标区域上方；物体仍停留在初始位置 `[0.43685, -0.18151, 0.01988]`。主要失败模式是模型频繁切换开合夹爪，并过早向目标移动，而不是先完成源方块对准与抓取。

## 结论

- Jev 作为高层技能选择器，在当前 9 局开发集上全部成功。
- Jev 直接控制逐步 XYZ 时，首局未能完成抓取；因此停止扩展，没有把单次失败包装成完整排行榜结论。
- 规则技能基线同样为 9/9，但无需 API、累计耗时仅 11.76 秒。Jev 高层技能组没有提高这个简单开发集的成功率，只增加了模型等待与费用。
- 每组 9 局仍属于小规模开发验证，不能证明对新任务的泛化能力。

## 复现命令

```bash
jev-embodied evaluate \
  --manifest benchmarks/builtin-dev.json \
  --output runs/revalidation-2026-09-24/jev-skills-dev \
  --policy jev \
  --connection-source saved \
  --control-mode skills \
  --observation-mode privileged \
  --max-steps 30 \
  --max-calls 60 \
  --timeout 180 \
  --threshold 0
```

输出目录必须不存在；如需复跑，请更换 `--output` 路径。API Key 从本机保存连接读取，不写入实验结果。
